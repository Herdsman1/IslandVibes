# Island Vibes — VTDI Assignment 1

## Project concept
Island Vibes is a responsive music and events website celebrating Jamaican reggae, dancehall and Caribbean music culture. The intended audience is people who want to discover music events and send an event registration request.

## Pages
1. `index.html` — home/landing page with a responsive navigation bar, feature sections and Bootstrap Carousel.
2. `artists-events.html` — event listings with a genre filter and a Bootstrap Modal populated using JavaScript.
3. `register.html` — registration form with client-side validation and a Bootstrap Toast confirmation.

## Technologies and concepts demonstrated
- **HTML5:** semantic `header`, `nav`, `main`, `section`, `article` and `footer` elements, labels, headings and alt text.
- **CSS3:** custom visual theme, layout, typography and a mobile media query.
- **Bootstrap 5:** responsive navbar, grid, cards, buttons, form controls, spacing utilities, Carousel, Modal and Toast.
- **JavaScript:** `const` and `let`, strings, numbers and booleans, an array of event objects, conditions, functions, loops, DOM selection/modification and event listeners.
- **jQuery:** selects the active navigation link and adds the `aria-current` attribute.
- **Bootstrap JavaScript:** Carousel, Modal and Toast components.

## How to run
1. Extract the project folder.
2. Open the folder in Visual Studio Code or another code editor.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. An internet connection is required for the Bootstrap, jQuery and remote image CDN links.
